## Wer wir sind

**Seraph-IT** ist ein deutscher Managed-IT- und Security-Dienstleister. Wir bauen
gehärtete, auditierbare Betriebsumgebungen für Mittelstand und KRITIS-nahe
Organisationen — auf Open-Source-Basis, mit klarer Compliance-Spur und ohne
Vendor-Lock-In.

<table>
<tr>
<td width="50%" valign="top">

### Was wir machen

- **Defensive Security** — Wazuh-SOC, Incident-Handling, Threat-Hunting
- **IT Service Management** — ITIL auf Frappe Helpdesk, Problem / Change / PIR
- **Compliance-Engineering** — NIS2, DSGVO Art. 28, BSI Grundschutz, ISO 27001
- **ERPNext-Maßanfertigungen** — Selling-Gates, Vertrags-Doctypes, Migrationen
- **Managed Services** — Workplace, M365, Backup, Server, VoIP, Access-Point

</td>
<td width="50%" valign="top">

### Wie wir bauen

- **Audit-first** — jeder Workflow taggt seine Compliance-Pflichten im Code
- **Test-first** — keine PR ohne grüne CI, kein Merge ohne Review
- **ADR-driven** — Architektur-Entscheidungen sind dokumentiert, nicht mündlich
- **Idempotent by default** — Migrations, Crons, Hooks: alles re-runnable
- **Defense-in-depth** — Tenant-Binding, PII-Redaktion, Fail-closed-Validatoren

</td>
</tr>
</table>
